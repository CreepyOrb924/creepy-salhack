# Contributing

Use Java 17 and the Gradle wrapper. Run `./gradlew build` before submitting a pull request. Keep Minecraft compatibility at 1.20.4 unless the change explicitly proposes another version. Include a concrete reproduction and validation for bug fixes; distinguish local tests from remote-server claims.

Preserve license and attribution notices. Do not contribute legacy decompiled code or assets without verified redistribution rights. Do not commit account/session data, tokens, personal worlds, game binaries, build caches or machine logs. Open issues with sanitized information only.

Feature and performance claims need supporting tests or measurements. Keep changes focused and document new settings. Contributions are submitted under the project's existing license.
